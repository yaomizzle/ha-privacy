Privacy Policy

Last updated: October 13, 2026

"Home Assistant (Personal Integration)" is a private application used by a single household to connect its own self-hosted Home Assistant server to its own Google Calendar. It is not a public service.

What data is accessed

With the owner's permission, the app accesses Google Calendar data (calendar names and events) in the owner's Google account, so events can be displayed on a home dashboard, trigger reminders, and be created or edited from the home server.

How data is used and stored

Calendar data is used only for the purposes above. It is processed on the owner's own Home Assistant server. Access tokens are stored on that server. Data is not sold, shared with, or transferred to any third party, and it is not used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions, or by removing the integration from Home Assistant.

Changes

This policy may be updated from time to time. The date above shows the latest revision.
